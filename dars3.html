CREATE TABLE- JADVAL YARATISH

SQL tilida CREATE TABLE buyrug'i ma'lumotlar bazasida yangi jadval yaratish uchun ishlatiladi.

💡 CREATE TABLE Sintaksisi

Jadval yaratishda har bir ustun uchun nom va ma'lumot turi (data type) ko'rsatilishi shart.

! Cheklovlar (Constraints) Ma'lumotlar sifatini ta'minlash uchun quyidagi kalit so'zlardan foydalaniladi: PRIMARY KEY: Jadvaldagi har bir qatorni takrorlanmas (unikal) qiladi. NOT NULL: Ustun bo'sh qolishi mumkin emasligini bildiradi. UNIQUE: Ustundagi qiymatlar takrorlanmasligini ta'minlaydi. DEFAULT: Agar qiymat kiritilmasa, avtomatik ravishda standart qiymatni qo'yadi. AUTO_INCREMENT: (MySQL da) ID raqamini avtomatik oshirib boradi. 2. Ma'lumotlar yaxlitligi (Data Integrity) CREATE TABLE jarayonida ma'lumotlarning aniqligi va ishonchliligini ta'minlash uchun cheklovlar (constraints) qo'llaniladi. Ilmiy klassifikatsiyaga ko'ra, bular quyidagilardir: Entitet yaxlitligi (Entity Integrity): PRIMARY KEY yordamida har bir yozuvning unikal bo'lishi ta'minlanadi. Referensial yaxlitlik (Referential Integrity): FOREIGN KEY orqali jadvallararo mantiqiy bog'liqlik o'rnatiladi. Domen yaxlitligi: NOT NULL va CHECK operatorlari orqali ustunga noto'g'ri ma'lumot kiritilishining oldi olinadi.
